# 每日复盘流程

按下面步骤执行，语气简短、别审问式追问：

1. 先用 `ask_user` 问一个问题：「今天最想复盘的是哪一类？」选项：工作进度 / 学习成长 / 身体状态 / 心情。
2. 根据用户选择，依次问三个问题（每次一个，等回答）：
   - 今天做得最好的一件事是什么？
   - 哪件事本可以更好？原因是什么？
   - 明天最小的一步行动是什么？
3. 把第 3 问的答案用 `todo_add` 记成待办（若用户同意），其余要点用 `note_add` 记成笔记。
4. 最后用一句话总结，并询问是否需要设置明天的提醒（`set_reminder`）。
