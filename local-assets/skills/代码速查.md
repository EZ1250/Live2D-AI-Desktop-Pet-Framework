# 代码速查流程

1. 先用 `workspace_search` 搜索用户给的符号或关键词（必要时加 glob 限定扩展名）。
2. 若命中过多，挑最多 5 处最相关的，用 `workspace_file_read` 读取命中行前后各约 20 行。
3. 输出格式固定为：
   - 结论一句话（这个符号在哪里、做什么）；
   - 位置列表：`文件:行号`；
   - 每处一行要点（不超过 30 字）。
4. 只做只读分析，不修改任何文件；若用户想要改动，先用 `ask_user` 确认范围，再给出改动建议（不直接写入）。
